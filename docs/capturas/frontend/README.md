# Evidencia de Pruebas Manuales de Frontend

Cada caso debe documentarse con una captura real del navegador, tomada mientras AgendaU está abierta y muestra el resultado esperado. No se deben usar capturas de terminal ni imágenes generadas.

| Prueba | Archivo de captura requerido | Instrucción |
|---------|------------------------------|-------------|
| FE-01 Obtener eventos | `fe-01-obtener-eventos.png` | Abrir la agenda y capturar la lista de eventos o el estado vacío. |
| FE-02 Crear evento | `fe-02-crear-evento.png` | Capturar el mensaje de creación exitosa y el evento visible en la lista. |
| FE-03 Editar evento | `fe-03-editar-evento.png` | Capturar el mensaje de actualización y los datos modificados. |
| FE-04 Eliminar evento | `fe-04-eliminar-evento.png` | Capturar el mensaje de eliminación y la ausencia del evento de prueba. |
| FE-05 Registrar participante | `fe-05-registrar-participante.png` | Capturar el participante registrado en su listado. |
| FE-06 Inscribir participante y consultar asistentes | `fe-06-inscribir-y-consultar-asistentes.png` | Capturar el mensaje de inscripción y el asistente mostrado para el evento. |

Conserve los nombres indicados. Si se utiliza otro formato de imagen, actualice simultáneamente este archivo y el documento técnico.
